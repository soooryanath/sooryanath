## 👨‍💻 About Me

Electronics Engineer with an MSc in Smart Electronic Systems from Riga Technical University, focused on **hardware test automation, multi-channel data acquisition, and statistical quality analysis** — backed by hands-on mixed-signal IC design experience.

* **Test & Automation:** Python-based tools using PyVISA, SCPI, and REST/JSON for multi-channel data acquisition, real-time pass/fail tolerance checking, and automated test workflows.
* **Data Analysis & QA:** QA pipelines in Python (pandas, NumPy) for statistical trend analysis, drift detection, and process capability (Cpk) reporting.
* **IC Design Background:** Designed and validated a 14-bit pipelined ADC system in Cadence Virtuoso — schematic capture, Verilog implementation, transient analysis, SNR/INL/DNL verification.

**Open To:** Hardware Test Engineer, Test Automation Engineer, and QA/Test Data Engineer roles.
